Add these permissions to a [role](/docs/access/roles). Picking a permission also adds the ones listed under **Requires**.

- **Global** permissions apply to the whole Manager.
- **Environment** permissions apply to every environment, or only to the environment a role assignment names.

Generate this list from your own install with `arcane permissions -o permissions.json`.
