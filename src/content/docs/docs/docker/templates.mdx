A template is a ready-made Compose file, with an optional env file, that you turn into a new project.

## Create a project from a template

1. Go to **Projects → Templates**.
2. Search by name, or filter by local or remote templates.
3. On the template card, select **Create Project**.

Other card actions:

- **View Details** shows the Compose file.
- **Download** saves a remote template locally for offline use.

## Add a local template

1. Create a folder in the Templates Directory. Its name becomes the template name.
2. Add a Compose file, such as `compose.yaml`.
3. Optional: add a `.env.example` or `.env` file.

```text
/app/data/templates
└── wordpress
    ├── compose.yaml
    └── .env.example
```

Arcane watches the directory and adds the template to the gallery. Compose files outside a folder are ignored.

The Templates Directory is `/app/data/templates` in Arcane's data volume by default. Change it with `ARCANE_TEMPLATES_DIRECTORY` or under **Settings → Storage & Limits**.

## Add a template registry

Remote templates come from registries. Each card names its source.

1. Go to **Projects → Templates → Manage Registries → Add Registry**.
2. Enter the registry URL. For the community registry, use:

   ```text
   https://registry.getarcane.app/registry.json
   ```

To publish your own, see [Template Registries](/docs/docker/template-registries).
