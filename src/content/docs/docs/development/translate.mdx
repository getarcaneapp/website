Translations happen in your browser on Crowdin, which opens pull requests against the Arcane repository for you.

## Translate strings

1. Open the [Arcane project on Crowdin](https://crowdin.com/project/arcane-docker-management).
2. Choose your language.
3. Open the `en.json` source file and translate the strings.

Once your translations ship, pick the language in **Account → Preferences**.

## Request a new language

If your language isn't on Crowdin yet:

1. [Open a language request on GitHub](https://github.com/getarcaneapp/arcane/issues/new?assignees=&labels=language-request&projects=&template=language-request.yml&title=%F0%9F%8C%90+Language+request%3A+%3Clanguage+name+in+english%3E).
2. Include the [ISO 639-1 language code](https://www.andiamo.co.uk/resources/iso-language-codes/) and the language's native name.
