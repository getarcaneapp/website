You need Docker Engine and Docker Compose.

## Install with Docker Compose

<Steps>

1. **Generate an encryption key.** Run this and copy the output:

   ```bash
   docker run --rm ghcr.io/getarcaneapp/manager:latest /app/arcane generate secret
   ```

2. **Create `compose.yaml`** with this content:

   ```yaml
   services:
     arcane:
       image: ghcr.io/getarcaneapp/manager:latest
       container_name: arcane
       ports:
         - '3552:3552'
       volumes:
         - /var/run/docker.sock:/var/run/docker.sock
         - arcane-data:/app/data
         - /opt/docker:/opt/docker
       environment:
         - ARCANE_APP_URL=http://localhost:3552
         - PUID=1000
         - PGID=1000
         - ARCANE_ENCRYPTION_KEY=<your-encryption-key>
         - ARCANE_PROJECTS_DIRECTORY=/opt/docker
       cgroup: host
       restart: unless-stopped

   volumes:
     arcane-data:
   ```

3. **Paste your key.** Replace `<your-encryption-key>` with the key from step 1.

4. **Set the address.** Change `ARCANE_APP_URL` to the address you will open. Keep `http://localhost:3552` if you only use Arcane on the Docker host. From other devices, use `http://<docker-host-ip>:3552`.

5. **Set your projects folder.** Replace all three `/opt/docker` values with the folder that holds your Compose projects. See [Projects folder](#projects-folder).

6. **Start Arcane.** In the folder with `compose.yaml`, run:

   ```bash
   docker compose up -d
   ```

7. **Open Arcane** at the `ARCANE_APP_URL` address.

8. **Sign in** with the default account:

   | Field    | Value          |
   | -------- | -------------- |
   | Username | `arcane`       |
   | Password | `arcane-admin` |

9. **Set a new password** when Arcane asks.

</Steps>

<Collapsible id="other-ways-to-generate-a-key" title="Other ways to generate a key" description="Use the Arcane CLI or OpenSSL instead of a container.">

The key must be 32 bytes, as raw text, base64, or hex.

With the Arcane CLI:

```bash
arcane-cli generate secret
```

With OpenSSL:

```bash
openssl rand -hex 32
```

</Collapsible>

<Collapsible id="install-script" title="Install with the Linux script instead" description="Installs Docker and Arcane in one command.">

```bash
curl -fsSL https://getarcane.app/install.sh | sudo bash
```

To uninstall, run the interactive uninstaller. It asks whether to keep Arcane data, the Arcane user and group, and Docker:

```bash
curl -fsSL https://getarcane.app/uninstall.sh -o /tmp/arcane-uninstall.sh && sudo bash /tmp/arcane-uninstall.sh
```

To remove everything without prompting:

> [!WARNING]
> This removes Arcane, its data, the Arcane user and group, and Docker packages. Run it only if you also want Docker gone from the machine.

```bash
curl -fsSL https://getarcane.app/uninstall.sh | sudo bash -s -- --force --remove-all
```

</Collapsible>

## Details

### Projects folder

Mount your projects folder at the same absolute path inside the container (`/opt/docker`, not `opt/docker`). Set `ARCANE_PROJECTS_DIRECTORY` to that path. Then:

- Relative mounts like `./config` resolve the same way for Arcane and Docker.
- Arcane can manage projects that already exist in that folder.

Other options:

- If you mount a different container path (such as `/opt/docker:/app/data/projects`), Arcane translates container paths to host paths automatically.
- To set the mapping yourself, use `ARCANE_PROJECTS_DIRECTORY=<containerPath>:<hostPath>`.
- If unset, `ARCANE_PROJECTS_DIRECTORY` defaults to `/app/data/projects`.

### PUID and PGID

The official images start as root to prepare the container, then drop to a non-root user. `PUID` and `PGID` set the host UID and GID for files Arcane creates. If omitted, they default to `65532:65532`.

### Mounts

| Mount                  | Purpose                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| `/var/run/docker.sock` | Connects Arcane to Docker. Use a [socket proxy](/docs/security/socket-proxy) to restrict access. |
| `arcane-data`          | Stores Arcane's database and application data.                                                   |
| Projects folder        | Holds your Compose projects. See [Projects folder](#projects-folder).                            |
| `/builds`              | Optional. Dockerfiles and build contexts for [Image Builds](/docs/docker/image-builds).          |
| `/backups`             | Optional. Exported volume [Backups](/docs/docker/backups).                                       |

To use an optional folder, add it under `volumes:` in `compose.yaml`:

- `/builds`: host path `/srv/arcane/builds:/builds` or named volume `arcane-builds:/builds`.
- `/backups`: host path `/srv/arcane/backups:/backups` or named volume `arcane-backups:/backups`.

Declare named volumes under the top-level `volumes:` section too.

<Collapsible id="selinux-hosts" title="SELinux hosts" description="Use a socket proxy or relabel the Docker socket mount.">

Pick one:

- **Use a socket proxy (recommended).** Run a proxy, set `DOCKER_HOST`, and add `:z` to the projects mount (`/opt/docker:/opt/docker:z`). See [Socket Proxy](/docs/security/socket-proxy).
- **Mount the socket directly.** Disable SELinux labeling on the Arcane container and relabel the projects mount:

```yaml
services:
  arcane:
    image: ghcr.io/getarcaneapp/manager:latest
    container_name: arcane
    ports:
      - '3552:3552'
    security_opt:
      - label:disable
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - arcane-data:/app/data
      - /opt/docker:/opt/docker:z
    environment:
      - ARCANE_PROJECTS_DIRECTORY=/opt/docker
```

</Collapsible>

<Collapsible id="container-health-check" title="Container health check" description="Add a Docker health check with the built-in arcane health command.">

`arcane health` checks `/api/health`:

```yaml
services:
  arcane:
    image: ghcr.io/getarcaneapp/manager:latest
    # ...
    healthcheck:
      test: ['CMD', './arcane', 'health', '--timeout', '2s']
      interval: 10s
      timeout: 3s
      retries: 5
      start_period: 15s
```

`start_period` gives Arcane time to finish first-boot database migrations before failed checks count toward `retries`.

</Collapsible>

<Collapsible id="external-postgres" title="External Postgres database" description="Store Arcane's data in Postgres instead of the built-in SQLite file.">

Set `ARCANE_DATABASE_URL` to use Postgres instead of the default SQLite file in `arcane-data`:

```bash
postgres://<db_username>:<db_password>@<postgres_url>:<postgres_port>/<postgres_db_name>
```

To switch back to SQLite, set it to:

```bash
file:data/arcane.db?_pragma=journal_mode(WAL)&_pragma=busy_timeout(2500)&_txlock=immediate
```

</Collapsible>

<Collapsible id="supported-architectures" title="Supported architectures" description="CPU architectures for the images and binaries.">

Docker pulls the matching `manager` or `agent` image for:

- `linux/amd64`
- `linux/arm64`
- `linux/arm/v7`
- `linux/riscv64`

Binaries on [GitHub Releases](https://github.com/getarcaneapp/arcane/releases/latest):

| Binary                          | Linux                                          | macOS             |
| ------------------------------- | ---------------------------------------------- | ----------------- |
| `arcane` (manager), `arcane-agent` | `amd64`, `arm64`, `armv7`, `386`, `riscv64` | `amd64`, `arm64` |
| `arcane-cli`                    | `amd64`, `arm64`, `armv7`, `386`, `riscv64`    | `arm64` only      |

</Collapsible>
