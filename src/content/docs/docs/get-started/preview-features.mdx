Preview features are off by default. They can have bugs, and they can change or be removed in a later release.

## Verify CLI self-update signatures

Enable Sigstore signature verification for `arcane-cli self-update`:

```bash
arcane-cli config set previews.newSelfUpdater true
```

See [Verify self-update signatures](/docs/reference/cli/config#verify-self-update-signatures) for details. To report a bug, [open an issue](https://github.com/getarcaneapp/arcane/issues) with your client and version.
