Preview features are unfinished. They're off by default, may have bugs, and can change or go away in a future release. Each client (web UI, iOS app, CLI) has its own toggle.

## All environments

<Badge text="Preview" variant="caution" />

Shows containers, projects, images, volumes, networks, ports, updates, and vulnerability scans from every enabled environment in one list, instead of switching between environments. Each item is tagged with its environment, and actions run against that environment.

Bulk actions like update checks, updates, and pruning run on every enabled environment, even if the list is filtered. Check the environment count in the confirmation before you continue.

<Tabs syncKey="arcane-client">

<TabItem label="Web UI">

Go to **Account** → **Previews** (click your avatar at the bottom of the sidebar) and turn on **All environments (preview)**. The setting is saved to your account, not the browser.

The same tab lets you choose whether lists show the environment name or just a colored dot, and set a color per environment.

To turn it off, use the same toggle or click **Turn off preview** in the environment switcher.

</TabItem>

<TabItem label="iOS app">

Go to **More** → **Preview Features** and turn on **All Environments**. You can also set a color per environment there.

The setting is per device. Turn it off to pick a single environment again.

</TabItem>

<TabItem label="CLI">

```bash
arcane-cli config set previews.allEnvironments true
```

Lists get an `ENVIRONMENT` column. Use `--env <id>` to target one environment for a single command. Set it back to `false` to go back to your default environment.

See the [CLI config reference](/docs/reference/cli/config#preview-every-environment) for details.

</TabItem>

</Tabs>
