Preview features are unfinished. They're off by default, may have bugs, and can change or go away in a future release. Each client (web UI, iOS app, CLI) has its own toggle.

## CLI signature verification

`arcane-cli self-update` can check each release's Sigstore signature before installing it. Turn it on with:

```bash
arcane-cli config set previews.newSelfUpdater true
```

See [Verify self-update signatures](/docs/reference/cli/config#verify-self-update-signatures) for details.

Found a bug? [Open an issue](https://github.com/getarcaneapp/arcane/issues) and mention which client and version you're on.
