A lot of you have been asking about Android since the iOS beta came out. It's finally here.

The iOS and Android apps are the same app now, so Android has everything the iOS version has, and updates will ship to both at the same time.

## Joining the beta

To get in:

1. Join the [Arcane Mobile beta group](https://groups.google.com/g/arcane-mobile-beta) with the Google account you use on your phone.
2. Open the [opt-in page](https://play.google.com/apps/testing/app.getarcane.android) and tap **Become a tester**.
3. Install [Arcane Mobile from Google Play](https://play.google.com/store/apps/details?id=app.getarcane.android).

If Play says the app isn't available, wait a few minutes and make sure you're signed into Play with the same account you joined the group with.

## It's a beta

Android hasn't had nearly as much testing as iOS yet, so you'll probably run into some bugs. If you do, open an issue on the [mobile repo](https://github.com/getarcaneapp/mobile/issues) or let us know in [Discord](https://discord.gg/WyXYpdyV3Z).

Setup info is in the [Arcane Mobile docs](/docs/settings/mobile-app).

Thanks for being patient on this one. Now go break it for us!
