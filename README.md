# Arcane Documentation Website

This repository holds [getarcane.app](https://getarcane.app): the landing page, documentation, blog, changelog, and tools like the Instance Generator. It's built with [Astro](https://astro.build) and [Starlight](https://starlight.astro.build), and uses [Vite+](https://viteplus.dev) for formatting, linting, and the commit hook.

## Developing

Install the dependencies and start the development server:

```bash
vp install
vp run dev
```
